
# Welcome to the Open Cybersecurity Alliance (OCA)

The Open Cybersecurity Alliance Community (hereafter, the OCA Community) exists to preserve and advance the mission, brand, and collaborative value of the Open Cybersecurity Alliance following the sunset of the OASIS Open Project model. The OCA Community provides a lightweight, sustainable framework for community-led collaboration, interoperability demonstrations, and innovation aligned with OASIS cybersecurity standards. For more information, please read the [OCA Community Governance](https://github.com/opencybersecurityalliance/oca-community-project/blob/main/COMMUNITY-GOVERNANCE.md).


## OCA sub-projects
